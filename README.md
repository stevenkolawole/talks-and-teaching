# Talks and Teaching

Slides, notebooks, code, and recordings from the talks, lectures, and workshops I have given since
2020 — on efficient ML and model compression, sign language understanding, open science, and doing
research without institutional backing.

Most of these talks were given at more than one venue, so folders are organized **by talk, not by
venue**, with every venue listed inside. Slide decks are archived here as PDFs so they stay readable
if the original links rot.

**Licensing:** slides, notes, and writing are [CC BY 4.0](LICENSE); code and notebooks are
[MIT](LICENSE-CODE). Reuse, adapt, and teach from any of it.
